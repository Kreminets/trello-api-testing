# Trello API Testing

API testing project for the Trello REST API using Postman.

## Project Overview

This project demonstrates practical REST API testing skills using Postman.

The project includes:
- API test cases
- Positive and negative test scenarios
- GET, POST, PUT and DELETE requests
- Postman collection
- Screenshots as test evidence

## Tested API Operations

- Create board
- Get board
- Update board
- Create list
- Create card
- Get card
- Update card
- Delete card
- Negative request for deleted card
